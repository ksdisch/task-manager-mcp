# todoist-mcp

Local stdio MCP server exposing Todoist operations. A personal Zapier replacement
that drops the 100-task/mo cap and exposes Todoist's native filter syntax to Claude.

> Status: Phase 1 of 4 — scaffold + `todoist_list_projects` only. Full tool surface,
> install guide, and filter cookbook land in Phase 4. See `PROJECT_SPEC.md` for the
> full plan.
